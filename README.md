# Filter & Fiber

A polished single-page cafe landing experience for **Filter & Fiber** (Indiranagar, Bangalore), built with **Vite + React** and a fixed **React Three Fiber** background scene.

## Tech stack

- React + Vite (JavaScript)
- Three.js
- @react-three/fiber
- @react-three/drei
- GSAP + ScrollTrigger

## Run locally

```bash
npm install
npm run dev
```

`npm run dev` starts the local development server.

## Other scripts

```bash
npm run build
npm run lint
npm run preview
```

## What is implemented

- Full-viewport fixed 3D canvas background
- Procedural floating coffee-cup scene (no external assets)
- Scroll-linked 3D motion and section reveal animations using GSAP ScrollTrigger
- Responsive hero/about/menu/footer layout
- Accessible styling with strong contrast, semantic sections, focus-visible states, and reduced-motion handling
